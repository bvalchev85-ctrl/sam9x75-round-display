Round Live Cam

Show the PIC64_WebCam feed inside the round display frame — live, in your browser. The feed is login-protected, so this works as a one-click bookmarklet on the camera page (a plain local file can’t authenticate to the LAN stream on its own).

  1. Add the button once: drag Round Cam up to your bookmarks bar.

    (Ctrl+Shift+B shows the bookmarks bar if it’s hidden.)

  2. Open the camera & sign in:
    Open camera ↗ login admin / admin → the live viewer
  3. Click Round Cam on that viewer tab — the live feed snaps into the round display (bezel, LIVE badge, orbiting rings). Click it again anytime you reopen the camera.
What the button does / copy the code

It restyles the camera’s own live <img id="cam"> (MJPEG from stream.php) into the round frame — same page, so the authenticated stream keeps flowing. Nothing is sent anywhere; it only changes how the page looks.


    

  


  
On the real RDK board this bookmarklet isn’t needed: the SAM9X75 sits on the LAN and pulls
  http://192.168.0.38/stream.php natively (GStreamer souphttpsrc → jpegdec → kmssink, or the EGT app),
  with no browser login/CSP in the way. Endpoint: host 192.168.0.38, path /stream.php, MJPEG multipart, 640×480.
